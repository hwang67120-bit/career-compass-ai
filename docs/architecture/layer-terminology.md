# 계층·컴포넌트 이름 정의

상태: 제안 — 노션 문서에 아직 반영되지 않음. 코덱스(Java 쪽 검토) 의견을 반영해 정리함.

## Java (`backend-java`)

- `pythonworker` 패키지: 오케스트레이션 계층 그 자체가 아니라, 오케스트레이션 계층 안에서 Python 비동기 호출을 실행하는 컴포넌트다.

## Python (`ai-python`)

- `services/`: 온라인 분석 유스케이스 계층. 요청이 들어왔을 때 추출·유사도·설명 생성 흐름을 조합하는 실행 시점 로직.
- `providers/`: 모델·외부 AI 호출 계층. Ollama·Gemini 등 실제 모델·외부 API 어댑터.
- `guardrails/`: 독립된 상하 계층이 아니라 입출력 경계에 적용되는 정책 영역(허용 필드, 근거, 개인정보 검사).
- `training/`, `evaluation/`: 오프라인 모델 개발 영역. 온라인 추론 서버(FastAPI 앱)와 분리하며, 운영 FastAPI가 이 영역을 import하지 않는다.

## 사용을 보류하는 용어

- "강화학습": 실제 강화학습 방식이 확정되기 전까지 사용하지 않는다. 지금은 "오프라인 모델 개발"로만 지칭한다.
